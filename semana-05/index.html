Estructura y operación de un Framework JS

Un framework como React organiza la interfaz en piezas reutilizables. Funciona con Client Side Rendering: el navegador descarga JavaScript y construye la página en el cliente.

  • 🖥️
    Client Side Rendering (CSR)

    El servidor entrega un HTML casi vacío y el JavaScript genera y actualiza la interfaz en el navegador.

  • 📦
    Gestión de dependencias

    Las librerías del proyecto se administran con un gestor de paquetes (npm) y se listan en package.json.

  • 🛠️
    Herramientas de creación de proyectos

    Herramientas como Vite generan la estructura inicial y un servidor de desarrollo.

npm create vite@latest mi-app
cd mi-app
npm install
npm run dev
🧱

Desarrollo basado en componentes

Una aplicación React se arma combinando componentes: funciones que devuelven parte de la interfaz escrita en JSX, una sintaxis parecida a HTML dentro de JavaScript.

📝

JSX

Permite escribir etiquetas dentro del código JavaScript e insertar valores con { }.

📨

Props

Datos que un componente padre envía a un componente hijo.

👶

Children

Contenido que se coloca entre las etiquetas de un componente y este lo muestra.

function Tarjeta({ titulo, children }) {
  return (
    <div className="tarjeta">
      <h2>{titulo}</h2>
      {children}
    </div>
  );
}

<Tarjeta titulo="Hola">
  <p>Contenido hijo</p>
</Tarjeta>
🎨

Utilización de estilos en un Framework JS

En React hay varias formas de aplicar estilos a los componentes:

✏️

Styles inline

Objeto de estilos en el atributo style del elemento.

📄

Style Sheets

Archivos .css importados en el componente.

🧩

Style Modules

CSS con alcance local al componente, para evitar choques de nombres.

💅

Styled Components

Estilos escritos dentro de JavaScript y asociados al componente.

🧰

Framework CSS

Uso de librerías como Bootstrap o Tailwind dentro de React.
