¿Cómo funciona la Web y el protocolo HTTP?

La Web opera mediante un modelo Cliente-Servidor. Cuando ingresamos una URL en el navegador ocurren los siguientes pasos:

  • 🔍
    DNS (Domain Name System)

    Traduce el nombre de dominio (ej. google.com) a una dirección IP numérica.

  • 🔗
    TCP/IP

    Se establece una conexión dividiendo los datos en paquetes para su transmisión.

  • 📡
    HTTP/HTTPS

    El cliente realiza una petición (GET, POST) y el servidor responde con un código de estado (200 OK, 404 Not Found) junto con los archivos solicitados.

Diferencias en Soluciones Web

📄

Página Web

Documento estático accesible mediante una URL (ej. about.html).

🌐

Sitio Web

Colección de páginas web bajo un mismo dominio.

⚡

Aplicación Web

Software interactivo en un servidor que maneja lógica de negocio, estado y bases de datos.

🏢

Sistema Web

Conjunto integrado de aplicaciones y servicios complejos.
