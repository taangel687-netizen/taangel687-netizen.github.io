1. Temas Aprendidos (Definiciones y Procedimiento)

¿Cómo funciona la Web y el protocolo HTTP?

La Web opera mediante un modelo **Cliente-Servidor**. Cuando ingresamos una URL en el navegador:

  • El DNS traduce el nombre de dominio (ej. google.com) a una dirección IP numérica.
  • Se establece una conexión mediante TCP/IP dividiendo los datos en paquetes.
  • El cliente realiza una petición HTTP/HTTPS (GET, POST) y el servidor responde con un código de estado (200 OK, 404 Not Found) junto con los archivos solicitados.

Diferencias en Soluciones Web

  • Página Web: Documento estático accesible mediante una URL (ej. about.html).
  • Sitio Web: Colección de páginas web bajo un mismo dominio.
  • Aplicación Web: Software interactivo en un servidor que maneja lógica de negocio, estado y bases de datos.
  • Sistema Web: Conjunto integrado de aplicaciones y servicios complejos.

Estándares y Roles (Open Web Platform)

Comprendí la diferencia entre las capas de desarrollo: Frontend (lo que ve el usuario con HTML, CSS, JS) y Backend (procesamiento en servidor y base de datos), regidos por estándares de la W3C.

2. Ejercicios de Laboratorio (Resultados)

Durante la sesión práctica se realizaron los siguientes procedimientos en Visual Studio Code:

  • Configuración del Entorno: Instalación de VSC y extensiones esenciales (Live Server, Prettier, Material Icon Theme).
  • Atajos de Teclado Practicados:
    • Ctrl + P para navegación rápida de archivos.
    • Ctrl + Shift + P para la Paleta de Comandos.
    • Ctrl + ~ para alternar la terminal integrada.
    • ! + Tab mediante Emmet para generar el boilerplate de HTML5.
  • Primer Archivo HTML: Creación de la estructura base y previsualización en tiempo real mediante Live Server.
  • Control de Versiones: Inicialización de repositorio local Git y publicación del código en GitHub.

3. Reflexión Metacognitiva

¿Qué aprendí?

Aprendí a diferenciar conceptualmente las arquitecturas web y a configurar un entorno de desarrollo profesional con Visual Studio Code, aplicando buenas prácticas de formateo automático y control de versiones con Git.

A través de la exposición teórica docente y la aplicación práctica guiada en laboratorio, ejecutando los comandos directamente en la terminal integrada y experimentando con el flujo de trabajo en tiempo real con Live Server.
