01

Recorrido de la Primera Unidad

La primera unidad del curso Desarrollo de Aplicaciones Web recorrió, semana a semana, el camino que sigue una aplicación web: desde entender cómo funciona la web hasta construir una aplicación completa con React. Cada semana se apoyó en la anterior.

🌐

Semana 01 — Fundamentos Web y entorno

Cómo funciona la web (DNS, HTTP), frontend vs backend y configuración de VS Code, Live Server y Git/GitHub.

📄

Semana 02 — HTML5, XML y CSS3

HTML semántico, XML, DOM, Flexbox, Grid, position y diseño responsivo con media queries.

🎨

Semana 03 — Bootstrap y Tailwind CSS

Frameworks CSS: sistema de rejilla y componentes de Bootstrap, y clases utilitarias de Tailwind.

⚡

Semana 04 — JavaScript, TypeScript, DOM y Canvas

Variables, funciones, closures, manipulación del DOM y animaciones con Canvas.

⚛️

Semana 05 — React: componentes, props y estilos

Client Side Rendering, Vite, JSX, props, children y formas de aplicar estilos.

📡

Semana 06 — Eventos, renderizado y APIs

Eventos, renderizado condicional e iterativo, promesas, async/await y Axios.

🪝

Semana 07 — Hooks y Evaluación de Logro 01

useState, useEffect y demás hooks, hooks personalizados y el parcial del sistema de biblioteca.

🧭

La línea de aprendizaje

🧱

Estructura y diseño

Semanas 1 a 3: cómo funciona la web, HTML, CSS y frameworks de estilos para construir y dar forma a las páginas.

⚙️

Comportamiento

Semana 4: JavaScript y TypeScript para dar vida a la página con funciones, DOM y animaciones.

⚛️

Aplicaciones con React

Semanas 5 a 7: componentes, eventos, consumo de APIs y hooks, hasta integrar todo en el parcial.

03

Reflexión de la Primera Unidad

Mirando las siete semanas en conjunto, esto es lo que me llevo de la unidad.

💡

¿Qué aprendí en la unidad?

Aprendí a construir una aplicación web de principio a fin: entender cómo viaja la información entre cliente y servidor, estructurar con HTML5 y estilizar con CSS3, Bootstrap y Tailwind, programar el comportamiento con JavaScript y TypeScript, y organizar la interfaz en componentes de React con eventos, consumo de APIs y hooks.

🎯

¿Cómo lo aprendí?

Combinando la teoría con la práctica cada semana: las exposiciones del Dr. Suasnabar y los laboratorios del Mg. Aguilar, donde escribía el código y lo probaba en el navegador. Documentar cada semana en este portafolio también me ayudó a repasar y ordenar lo aprendido, y el parcial en equipo me exigió unirlo todo.

🧭

¿Para qué me sirve?

Para desarrollar el frontend de mis proyectos fullstack y entender cómo se conecta con el backend. Es la base para crear aplicaciones reales, como los sistemas que desarrollo en la universidad y en mis proyectos personales.

🧩

¿Qué dificultades tuve?

El salto de JavaScript a React, sobre todo entender el flujo de datos con props, el comportamiento asíncrono al consumir APIs y las dependencias de useEffect. También organizar el trabajo en equipo y el tiempo en el parcial.

🛠️

¿Cómo las superé?

Practicando con ejemplos pequeños, usando la consola del navegador para ver qué ocurría, revisando la documentación y dividiendo el trabajo por módulos con mi equipo para integrarlo paso a paso.

🚀

¿Cómo lo aplicaré?

Usaré lo aprendido en mis proyectos con React y en lo que viene del curso: hooks personalizados, manejo de estado y conexión con un backend propio. Mantendré este portafolio como registro de mi avance.

🔭

Lo que sigue

Con la base del frontend lista, la siguiente unidad lleva estos conocimientos a aplicaciones más completas. Mi meta es llegar con los temas de esta unidad bien afianzados, apoyándome en la retroalimentación recibida.
