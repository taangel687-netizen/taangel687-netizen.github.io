Estándar Open Web Platform

La Open Web Platform es el conjunto de tecnologías abiertas que permiten el desarrollo web. Está estandarizada por el W3C para garantizar la compatibilidad entre navegadores.

📝

HTML5

Lenguaje de marcado que define la estructura y el contenido de las páginas web.

🎨

CSS3

Hojas de estilo que controlan la presentación visual y el diseño.

⚙️

JavaScript

Lenguaje que añade interactividad y comportamiento dinámico.

📦

XML

Lenguaje de marcado extensible para estructurar datos de forma legible.

📦

HTML vs XML

Ambos son lenguajes de marcado, pero con propósitos distintos: HTML define cómo se muestra el contenido y XML describe y transporta datos con etiquetas que define el propio usuario.

<?xml version="1.0" encoding="UTF-8"?>
<estudiante>
  <nombre>Angel</nombre>
  <curso>Aplicaciones Web</curso>
</estudiante>

En XML todas las etiquetas deben cerrarse y estar correctamente anidadas.

🌳

Árbol DOM (Document Object Model)

El DOM representa la estructura de un documento HTML como un árbol de nodos, donde cada elemento es un nodo que puede ser manipulado mediante JavaScript.

  • 🔷
    Árbol de Nodos

    Cada elemento HTML se convierte en un nodo del árbol. Los nodos pueden tener padres, hijos y hermanos, formando una jerarquía.

  • 🎬
    Renderizado

    El navegador lee el HTML, construye el DOM, aplica los estilos CSS y finalmente renderiza la página visible.

  • ♻️
    Ciclo de Vida

    La página web pasa por distintas etapas: carga del HTML, construcción del DOM, aplicación de estilos, ejecución de JavaScript, y finalmente el renderizado completo.

🏷️

Etiquetas Principales de HTML5

HTML5 introduce etiquetas semánticas que dan significado al contenido:

<header> - Encabezado de la página o sección
<nav> - Menú de navegación
<main> - Contenido principal
<article> - Contenido independiente
<section> - Sección temática
<aside> - Contenido relacionado
<footer> - Pie de página

Usar etiquetas semánticas mejora la accesibilidad y ayuda a los lectores de pantalla a navegar el contenido.

02

Diseño de Páginas con CSS3

🎨

Sintaxis y Selectores CSS3

CSS3 permite aplicar estilos a elementos HTML mediante selectores. La sintaxis básica consiste en: selector { propiedad: valor; }

/* Selector de clase */
.mi-clase {
  color: #00d4ff;
  font-size: 16px;
}

/* Selector de ID */
#mi-id {
  background: #0a192f;
}
📏

Block, Inline e Inline-Block

⬜

Block

Ocupa todo el ancho disponible y siempre empieza en una nueva línea. Ejemplo: <div>, <p>

▫️

Inline

Solo ocupa el espacio de su contenido y no acepta width/height. Ejemplo: <span>, <a>

◾

Inline-Block

Se comporta como inline pero permite width/height. Lo mejor de ambos mundos.

📐

Unidades de Medida

  • 📍
    Absolutas

    px (píxeles) - Tamaño fijo, no cambia con el zoom del usuario.

  • 🔄
    Relativas

    % (porcentaje) - Relativo al elemento padre. em y rem - Relativos al tamaño de fuente. vw/vh - Relativos al viewport (ancho/alto de la ventana).

📦

Flexbox Layout

Flexbox es un modelo de diseño unidimensional que facilita la distribución de elementos en una fila o columna.

.contenedor {
  display: flex;
  justify-content: center; /* Horizontal */
  align-items: center; /* Vertical */
  gap: 1rem; /* Espacio entre elementos */
}
flex-direction justify-content align-items flex-wrap flex-grow flex-shrink
🎯

Grid Layout

Grid es un sistema bidimensional para crear layouts complejos con filas y columnas.

.grid-contenedor {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 2rem;
}
📍

Tipos de Position

📌

Static

Posición por defecto. El elemento sigue el flujo normal del documento.

🔗

Relative

Se desplaza respecto a su posición original sin afectar otros elementos.

📍

Absolute

Se posiciona respecto al ancestro más cercano con position relative/absolute.

🎯

Fixed

Se fija en una posición de la pantalla incluso al hacer scroll.

📎

Sticky

Mezcla entre relative y fixed. Se pega al hacer scroll hasta cierto punto.

📱

Diseño Fluido vs Diseño Responsivo

Diseño Fluido

Usa porcentajes y unidades relativas

% vw/vh em/rem

Diseño Responsivo

Adapta con media queries

@media Breakpoints Mobile First
/* Media Query para móviles */
@media (max-width: 768px) {
  .contenedor {
    flex-direction: column;
  }
}
